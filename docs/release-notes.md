# 1.0.0

- A distinct Catppuccin Mocha Eira theme, using the canonical Mocha palette.
- Mauve actions; consistent surfaces, semantic feedback and desktop/mobile player styling.
- Palette/contrast tests, additive theme registration and a pinned Navidrome 0.64.2 build.
- Windows installer with checksum verification, private rollback/database backups and account-preservation checks.

This is a customized theme build, not an official Navidrome release. The application backend is built from the pinned upstream commit; library, account and networking settings are not part of the public package. Review the README before applying it, especially the rebuild requirement for future upgrades.
